# Laravel application — Donation Management System

This folder is the Laravel 13 app. **Project rules live in `../CLAUDE.md`** (repository root) and requirements in `../docs/srs.md`. Read both before working.

- Run all `php artisan`, `composer`, `npm` and `./vendor/bin/*` commands from this folder.
- Do not install Laravel Boost or any other package unless the user approves it (see the Stack table in `../CLAUDE.md`).
- Do not run remote install scripts (`curl … | bash`).
- Before saying a task is done: `composer check` must pass.
